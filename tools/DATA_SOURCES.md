# 词库数据来源与生成说明（v2.8 起）

端侧 `app/src/main/assets/web/data_wubi.js` 是**离线生成**的产物，运行时不产生任何词库外字符串。

## 两类数据

| 数据 | 作用 | 是否提交仓库 |
|---|---|---|
| 单字 / 一~四级简码 | 完全保留五笔86原方案 | 已含（`wubi86_official.dict.yaml`、`wubi86_jidian.dict.yaml`） |
| 词组（≥2字） | 规范现代汉语白名单，按五笔取码规则生成 | 只提交生成产物 `data_wubi.js` |

## 词组白名单与过滤（离线，全可审计）

词组生成需要两份**外部原始数据**，因体积与内容原因**不提交本仓库**，请自行获取后放入仓库**上级的构建目录**（与 `gen_wubi_data.js` 同级）：

1. **现代汉语词频白名单** `modern_words.txt`
   - 来自 jieba 分词的词典（含词频，格式 `词 词频 词性`）；
   - 仅取词频 `≥10` 的纯中文词（约 9.6 万），剔除长尾生造。
2. **第三方违禁词大表** `blacklist_raw.txt`
   - 仅用于过滤**低频词**中的违禁/脏词；
   - 该大表假阳性较高（会误伤"手机/公司/电话"等常用词），故生成逻辑对**词频≥500 的高频常用词豁免此大表**（真正违禁词不会有高词频）。
3. **话题红线**（直接固化在 `gen_wubi_data.js` 的 `TOPIC`，约 337 词，所有词频都过滤、不豁免）
   - 不涉及：国家 / 政策 / 政治 / 宗教 / 战争 / 民族 / 民俗，以及黄赌毒、脏话、极端消极词。

## 生成命令

```bash
node gen_wubi_data.js
# 输出端侧按字数：{1:12505,2:53979,3:25486,4:10448,5+:约1400}
```

## 用户私有白名单（运行时唯一"新词"来源）

- 用户**主动上屏**的多字词，若静态词库未收、且通过安全预检（不含话题/违禁词根），才存入本机 `cw_user_words`；
- 精确匹配、用户词之间不连锁（A、B 各自学习不代表"AB"成词）、上限 1000、可在设置中一键清空；
- 全部数据仅存本机，不上传。

> 原则：宁可漏词，不可违规。
